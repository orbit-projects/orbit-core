# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories for this repository.
Do not include exploit details in a public issue.

Please include the affected version, a minimal reproduction, impact, and any mitigation you have
identified. Maintainers will acknowledge reports within seven calendar days and coordinate a fix and
disclosure timeline with the reporter.

Orbit supports the latest released minor version and the current development branch. Security fixes
are documented in the changelog and published in GitHub Security Advisories.
