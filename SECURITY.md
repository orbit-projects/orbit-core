# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories for this repository.
Do not include exploit details in a public issue.

Please include the affected version or commit, affected component, a minimal reproduction or
technical description, security impact, and any mitigation you have identified. Redact credentials,
personal data, and production endpoints from the report.

Maintainers aim to acknowledge reports within seven calendar days. They will assess severity,
coordinate a fix and disclosure timeline with the reporter, and credit the reporter when requested.
Do not use this process for general support or feature requests.

Orbit supports the latest released minor version and the current development branch. Security fixes
are documented in the changelog and published in GitHub Security Advisories when disclosure is
appropriate. Orbit Core's provider-neutral contracts do not certify the cryptography, identity
configuration, or deployment security of an adapter or plugin.
